# Student Performance Prediction

## Project Overview
This machine learning project predicts a student's final grade (G3) using academic and personal factors.

## Technologies Used
- Python
- Pandas
- Scikit-Learn

## Algorithm
- Linear Regression

## Workflow
1. Load Dataset
2. Check Missing Values
3. Feature Selection
4. One-Hot Encoding
5. Train-Test Split
6. Model Training
7. Prediction
8. Evaluation

## Result
R2 Score: 0.78
